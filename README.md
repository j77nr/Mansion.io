# Atelier Ravel

Site éditorial de l’Atelier Ravel, consacré à l’architecture contemporaine, au design intérieur et aux projets du studio.

## Stack

- React et TypeScript
- TanStack Start et TanStack Router
- Vite et Tailwind CSS

## Développement local

Prérequis : Node.js et npm.

```sh
npm install
npm run dev
```

## Vérifications

```sh
npm run lint
npm run build
```
